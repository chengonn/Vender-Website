## 最終整合檢查

- `check:page -- shared-final tests`：格式、型別與全套測試通過。
- 全套 Vitest：13 個測試檔案、33 項測試通過。包含 27 項頁面測試、4 項 mock service 測試、2 項可選只讀介面測試。
- `npm run lint`：通過，最終無警告。
- `npm run build`：成功完成編譯、TypeScript 與頁面產生。沒有部署。
- 11 個明示頁面在本機 Next.js 開發伺服器皆 HTTP 200，詳見 [http-checks.json](http-checks.json)。

最後調整包括：Admin 側欄從路由判斷展示視角、待供應商確認的對帳引用已鎖定原單、固定申報金額與其示範費用內容一致。共用調整後重新執行全套測試。

## 驗證邊界

- 互動測試使用 jsdom／Testing Library；未執行真實瀏覽器 E2E、截圖比對或人工 UAT，不宣稱這些已通過。
- CSS 已包含手機側欄、窄螢幕排列及表格水平捲動；尚未做真實裝置視覺驗收。
- HTTP 200 只證明路由可編譯回應，不代替完整操作驗收。
- WebMCP 僅測試模擬 registry 的名稱、唯讀屬性、資料範圍、錯誤參數及解除註冊；未於支援該 API 的真實瀏覽器驗證。
- 無正式身份驗證、RBAC、API、資料庫、帳務計算、期限判斷或 Invoice，因此不宣稱正式安全與帳務驗收完成。
- Phase 0 的核心五項仍未定案；本次完成的是使用者另行授權的 Phase 1 初始前端模板。
